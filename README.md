# 漢字超戦（かんじちょうせん）Kanji Hyper War.

文字・UTF-8記号のみ（画像・絵文字不使用）のブラウザ向けシューティングゲーム。HTML5/Canvas実装。

グローバルランキング用に hashes.txt.gz を必要とする。

▶ [motoikenkichi.com](https://motoikenkichi.com/) からゲームプレイでプレイ可能
